# CloudScale Web Platform

## Project Overview

CloudScale Web Platform is a cloud-hosted website designed to demonstrate modern DevOps and Cloud Administration practices.

## Technologies

- GitHub
- HTML5
- CSS3
- Docker
- Nginx
- Azure Virtual Machines
- GitHub Actions
- Azure Monitor
- Azure VM Scale Sets

## Features

- Automated CI/CD Deployment
- Docker Containerization
- Azure VM Hosting
- Load Balancing
- Auto Scaling
- Stress Testing
- Monitoring and Alerting
